# Form3

> Form3 is a cloud-native, Payments-as-a-Service platform offering account-to-account payment processing to banks and fintechs through a single, unified REST API built on the json:api specification. It connects customers to UK Faster Payments, Bacs and CHAPS, SEPA Credit Transfer, SEPA Instant and SEPA Direct Debit, and US instant rails, with Confirmation of Payee / Verification of Payee, direct debit mandate management, scheme-addressable account identification, event notifications (webhooks) and full audit trails. Access is contracted (regulated B2B), authenticated with OAuth2 client-credentials plus HTTP Message Signatures request signing and, in some environments, mutual TLS.

## API

- [Form3 Public API (Swagger 2.0)](https://raw.githubusercontent.com/api-evangelist/form3/refs/heads/main/openapi/form3-payments.yml): One REST API, host api.form3.tech, basePath /v1, 163 paths / 186 operations, media type application/vnd.api+json.
- Base URL: https://api.form3.tech/v1
- Token endpoint: https://api.form3.tech/v1/oauth2/token (OAuth2 client-credentials)

## Conventions

- json:api resource envelopes: `{ "data": { "type", "id", "organisation_id", "attributes" } }`.
- Idempotency: creates use a client-supplied UUID `id`; a duplicate returns HTTP 409 with the stored resource (no Idempotency-Key header).
- Optimistic concurrency via an integer `version` field.
- Pagination: `page[number]`, `page[size]`, `page[after]` (cursor), default page size 100.
- Filtering: `filter[<attribute>]`.
- Errors: flat `{ error_code (uuid), error_message }` envelope (not RFC 9457).
